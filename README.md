## 先分清四层 IP：机房、原生、家宽、双 ISP

TikTok 判断一个账号像不像真人，看设备、行为、网络环境三层，网络环境里最先被扫的是 IP。机房 IP 的 ASN 一查就是商用出口，平台直接归到"非真人"那一类；那些几十块一年的廉价 VPS，绝大多数属于这一层，用它发内容，轻则限流，重则号没了。

往上第一层是原生 IP：IP 的注册归属地和服务器实际所在国家一致，机房在洛杉矶、whois 也显示美国。这是做 TikTok 的最低门槛。

第二层是家宽 IP：IP 从当地 ISP 的家庭宽带段出来，检测工具里显示的是运营商名字，看起来就是本地人在家刷手机。

第三层是双 ISP：同一个 IP 同时具备两个 ISP 属性，抗封能力更强，养号和直播都更稳。

这里有个被大部分推荐文糊弄过去的差别：**原生 IP 和家宽 IP 不是一回事**。原生只说明"注册地和机房对得上"，并不保证这个 IP 长得像家庭宽带。WePC 的套餐页把两者分开标注，写"原生 IPv4"的和写"原生家宽 IPv4"的是不同产品，下单前看清楚这一行字，比看价格更重要。

另外，WePC 的 TikTok_VPS 系列全部标配独立静态 IPv4，一台机器一个 IP，不与他人共用。做矩阵要守"一机一号一IP"，每个账号一套独立环境绑一个固定 IP，多号共用一个出口很容易被关联。

## 上手会踩的三个坑

**SSH 端口不是 22。** WePC 的 SSH 登录端口是随机分配的，要在控制面板里查。这个设计是为了避免端口被批量扫描、保护 IP 纯净度，但新手十有八九会以为是机器开不起来，白折腾半小时。
